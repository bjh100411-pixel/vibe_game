# ASHEN VEIL — Dark Fantasy Roguelike

브라우저에서 실행되는 2D 로그라이크 액션 게임입니다. 외부 게임 엔진·이미지·오디오 파일 없이 Canvas 2D와 Web Audio API로 동작합니다.

## 실행

**Windows:** Python 3이 설치된 상태에서 `run.bat`을 더블 클릭합니다. 로컬 서버가 실행되고 브라우저가 열립니다.

**macOS / Linux:** 터미널에서 이 폴더로 이동한 뒤 `./run.sh`를 실행합니다.

**직접 실행:** 프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속합니다. JavaScript 모듈을 사용하므로 `file://`로 index.html을 직접 여는 방식은 브라우저 정책상 지원하지 않습니다.

## 조작

- `W A S D`: 이동
- 기본 공격: 마우스 커서 방향으로 자동 발사 (좌클릭 불필요, 자동 조준 없음)
- `SPACE`: 대시 / 회피 (쿨타임 2.1초)
- `Q`: 영혼 폭발 (쿨타임 12초)
- `ESC`: 일시정지 / 재개

**모바일:** 화면 왼쪽의 투명 조이스틱으로 이동합니다. 공격은 자동으로 발사되고 가장 가까운 적을 자동 조준합니다. 오른쪽 버튼으로 회피와 필살기를 사용합니다. 터치 입력이 감지되는 기기에서만 모바일 조작이 표시되며, PC 조작은 기존 마우스 조준 방식을 유지합니다. 모바일은 가로 화면 플레이를 권장합니다.

## 현재 포함된 콘텐츠

- 5개 스테이지 / 총 20개 방
- 일반 적 8종, 엘리트 적, 보스 3종 (보스 공격 전 붉은 위험 예고 표시)
- B/A/S 등급 유물 37종 및 6종 능력치 보상
- 무작위 방 배치, 장애물, 적 배치
- 플레이어 성장 수준을 반영하는 적 능력치 스케일링
- 아이템 효과: 분열탄, 번개 연쇄, 화상, 처치 폭발, 흡혈, 저체력 광전사, 대시 강화, 자동 정령, 관통 창, 광역 파동 등
- 보상 선택, 경험치/레벨, 게임 오버, 클리어 결과 및 플레이 타이머
- 화면 흔들림, 피격 무적, 넉백, 데미지 숫자, Web Audio 절차적 배경 앰비언트 및 효과음
- Canvas 기반 다크 판타지 도형 스프라이트와 등급별 유물 UI (별도 이미지·오디오 파일 불필요)

## 폴더 구조

```text
src/
  config.js                설정 및 난이도 파라미터
  main.js                  시작점
  core/                    Game, Input, RoomManager, Effects, Audio
  entities/                Player, Enemy, Boss, Projectile
  data/                    아이템·적·보스·스테이지 데이터
  systems/                 성장형 난이도 및 보상 시스템
  ui/                      HUD, Menu, RewardScreen, ResultScreen
```

## 조정 포인트

- 아이템: `src/data/items.js`
- 적과 스테이지별 적 풀: `src/data/enemies.js`
- 보스: `src/data/bosses.js`
- 스테이지/방 수: `src/config.js`, `src/data/stages.js`
- 적 성장 곡선: `src/config.js`의 `ENEMY_SCALING` 및 `src/systems/Difficulty.js`
- 등급 확률: `src/config.js`의 `rarity`, `src/systems/RewardSystem.js`의 `pickGrade()`

## 데스크톱 패키징

Electron 실행 진입점(`desktop/main.cjs`)과 빌드 설정(`package.json`)을 포함했습니다. Node.js 설치 후 프로젝트 폴더에서 다음 명령을 실행하면 됩니다.

```bash
npm test             # 핵심 진행 흐름 스모크 테스트 (설치 불필요)
npm install
npm run desktop      # 데스크톱 개발 실행
npm run dist         # 현재 운영체제용 패키지 생성
```

브라우저 버전은 Electron 없이도 별도로 실행할 수 있습니다.

### GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다(예: `ashen-veil`). GitHub Free를 사용하는 경우 Pages 공개 사이트는 Public 저장소로 만들어야 합니다.
2. 이 프로젝트 폴더 안의 `index.html`, `style.css`, `.nojekyll`, `src/`, `README.md` 등을 저장소 최상위(root)에 업로드합니다. `dark-roguelike` 폴더 자체를 한 단계 더 중첩해 업로드하지 마세요. `index.html`이 저장소 최상위에 있어야 합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**에서 **Deploy from a branch**를 고릅니다.
5. Branch는 `main`, 폴더는 `/(root)`로 선택하고 **Save**를 누릅니다.
6. Pages 화면에 표시되는 사이트 주소로 접속합니다. 첫 배포는 반영까지 몇 분 걸릴 수 있습니다.

Git 명령으로 업로드하려면 프로젝트 폴더에서 다음을 실행합니다.

```bash
git init
git add .
git commit -m "Deploy Ashen Veil v2.0"
git branch -M main
git remote add origin https://github.com/내아이디/ashen-veil.git
git push -u origin main
```

`내아이디`는 본인의 GitHub 사용자명으로 바꿉니다. `git remote add origin`은 저장소 연결을 처음 할 때만 실행하며, 이미 원격 저장소가 연결돼 있다면 `git remote set-url origin https://github.com/내아이디/ashen-veil.git`을 사용합니다.
